### Welcome to GUTS GONE SOUR

This is my vibe-coded Olivia Rodrigo fanpage, it's deliberately silly and nonsensical.

What I learned from this project was not technical, but just how it's fun to make something silly and very bad, sometimes. I'm both impressed with the vibecoded portions of the site and bored of how stereotypically "ai" it looks. 

My favorite part was making it flash random song titles every once in a while, because I thought that had no purpose and was just fun.
